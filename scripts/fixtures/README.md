# Локальные товары магазина

`rewards.json` содержит 100 товаров выбранного оформления. Обложки находятся
в `static/web/shop/`, соответствующие Android-ресурсы — в `static/android/res/drawable-nodpi/`.
`audience_all` задаёт общий доступ при первом импорте нового лота;
Все 100 товаров имеют `audience_all: true` — доступны всем участникам пространства.
Для каждого товара заданы название, описание, условия, обложка, категория, цена и доступность.
Новые обложки `reward-005`…`reward-100` сгенерированы отдельно для каждого товара
через встроенный ImageGen; точные промпты находятся в `reward-image-prompts.json`.
Импортер до изменения данных проверяет наличие и PNG-заголовок всех обложек.

Импорт в уже запущенный локальный dev-сервер:

```sh
uv run --project backend python scripts/import_reward_fixtures.py
```

По умолчанию импортирует магазин «Алекс · демо → Луна · демо». Для других
синтетических участников используйте `--author` и `--recipient`. Адреса API и
интерфейса задаются через `--api` и `--origin`; разрешён только loopback HTTP.
Нужны включённый DEBUG-вход и существующие активные отношения с взаимным согласием
и правом `rewards.grant`. Импорт использует обычные серверные проверки прав.

Повторный последовательный запуск сохраняет существующие товары по точному
названию. Не меняет их цены, версии, доступность и обложки; не начисляет валюту,
не создаёт покупки, не сбрасывает данные. Если товар скрыт, импорт не включает
его повторно. Цена из фикстуры применяется только к новому лоту.
Запускайте импорт последовательно, без параллельных экземпляров.

Фикстуры не подключены к production-запуску или клиентскому каталогу:
оба клиента получают импортированные товары через API.
