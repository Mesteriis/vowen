Каждая запись содержит `uid`, `name`, `description`, `icon`, `url`, `extra`. UID стабилен: UUIDv5 с namespace `3e181b46-6a16-4c04-8acb-667ba0fd25a9` и именем `<kind>:<extra.code>`. `icon` и `url` по умолчанию null. `extra.code` — устойчивый код фикстуры, у часовых поясов также есть `extra.iana`.

Справочники предпочтений по полу/гендеру исключены по уточнению пользователя. Существующая модель отношений этим изменением не меняется.

24 часовых пояса — ограниченный региональный набор IANA без технических алиасов; это не перечень всех мировых зон. UTC и Europe/Madrid включены. Смещения не зафиксированы в JSON: IANA-идентификатор позволяет вычислять переходы на летнее время на нужную дату.

Миграция 0027 загружает начальные записи; 0028 сокращает ранее установленный список часовых поясов до 24. Исторические снимки зон для воспроизводимости/отката находятся отдельно в `backend/migrations/fixtures/`. Они не используются текущей загрузкой фикстур.

Повторная загрузка: `appctl references seed` с явно выбранным DATABASE_URL. Импорт использует ON CONFLICT DO NOTHING и не перезаписывает сохранённые записи или добавленные практики. Не менять UID опубликованных записей. Изменения уже установленного набора проводить следующей миграцией с собственным неизменяемым снимком.

Миграция 0029 добавляет nullable url всем пяти таблицам и недостающие практики из собственного снимка. v1 остаётся неизменяемым историческим набором для 0027. v2 сохраняет исходные UID и добавляет 88 практик, все URL пока null. Откат 0029 сохраняет записи практик и удаляет столбец url.

Уточнение 2026-10-18: v3 — справочник сексуальных и BDSM-практик, а не общих совместных занятий. 100 нейтральных терминов без инструкций; все url/icon null. 0030 заменяет только неизменённые фикстуры v2, сохраняя пользовательские записи и правки. Совпадающие понятия сохраняют UID. v1/v2 и старые миграционные снимки остаются историческими. При наличии пользовательских записей общее число строк может превышать 100.

v4 нормализует категории: `practice-categories.json` содержит «Секс» и «BDSM», в практиках `category_uid` ссылается на UID категории; категория больше не хранится в description/extra. Сначала загружаются категории, затем практики. Alembic 0031 переводит установленный v3 без перезаписи пользовательских описаний. Исторические наборы не редактируются.

v5 уточняет категории (12) и оставляет 89 практик. Восемь контекстных вариантов объединены с основными через extra.aliases; три общих заголовка заменены категориями. aliases — массив альтернативных названий для поиска. Ссылки category_uid остаются внешними ключами, url/icon null. 0032 обновляет только точные старые фикстуры; пользовательские записи/правки и используемые ими прежние категории сохраняются. Исторические наборы/снимки не изменять.

v6 добавляет независимый справочник составов участников (10 записей) и 4 практики в новую категорию «Групповые практики». МЖМ/ММЖ/ЖММ — одна запись с альтернативными названиями; порядок букв не задаёт роли или взаимодействие. extra.participant_count/men/women описывают условную численность, null означает отсутствие детализации. Никакие личные пол/гендер/предпочтения из этого не выводятся. Alembic 0033 и отдельные снимки дополняют существующий набор, сохраняя правки.

v7 добавляет общие девайсы/части тела. practice-devices.json (21 пара) и practice-body-parts.json (11 пар) — отдельные наборы внешних ключей, не справочные записи. Seed сначала загружает справочники, затем связи. ON CONFLICT DO NOTHING сохраняет дополнения. extra.discipline_default определяет общую часть выбора в наказаниях; дополнения отношений не входят в эти файлы. Все url/icon пока null.

v8 добавляет материалы, ролевые сценарии, форматы взаимодействия и места проведения отдельными справочниками. Все записи содержат extra.code/aliases, icon/url null. UUIDv5 используют прежний namespace и собственный kind. 0036 использует отдельные неизменяемые снимки для четырёх таблиц; старые наборы не редактируются. Новые справочники не создают личных предпочтений и не меняют ранее загруженные практики/связи.

v9 добавляет нейтральные справочники заболеваний/состояний и аллергенов. Только code/aliases в extra, без персональных диагнозов, медицинских допусков и автоограничений практик. URL/icon null. Сверка терминов и источники: docs/features/health-reference-catalogues.md. Alembic 0037 использует отдельные снимки; предыдущие версии не меняются.

v10 структурирует существующее без новых таблиц/записей: extra.group разделяет средства фиксации и аксессуары динамики; категория care с прежним UID называется «Восстановление и забота», её записи имеют группы «Телесная забота» / «После практики». 0038 обновляет восемь точных исходных строк по снимку before/after; пользовательские изменения и связи не перезаписывает. По-прежнему 280 записей, исторические версии не меняются.
