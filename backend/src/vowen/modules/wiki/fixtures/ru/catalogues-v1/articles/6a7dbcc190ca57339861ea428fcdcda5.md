## Значение

Иное выбранное частное пространство.

Категория предназначена для выбранного частного пространства, которое не описывается остальными вариантами. Она сохраняет возможность точного личного описания без добавления нового общего типа для каждого случая.

## Отличия и контекст

«Другое» не означает отсутствие условий. Для конкретной встречи отдельно уточняют доступ, присутствующих людей и ограничения площадки. Чувствительные сведения о месте можно обсуждать лично, не публикуя их в общей базе знаний.
