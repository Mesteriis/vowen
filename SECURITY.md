# Security policy

This project is a technical alpha, not independently audited or ready for real
sensitive records. Only the current development branch receives fixes.

Use GitHub private vulnerability reporting for this repository. If private
reporting is unavailable, open a neutral issue asking for a private contact
without disclosing the vulnerability, secrets or personal material.
Use synthetic reproduction data only. Do not attach real Telegram IDs,
initData, tokens, diaries, agreements, answers, server addresses or database dumps.

Server-side encryption is not E2EE: a server operator with code, root and keys
can access data. Self-declared adulthood is not verified age. See
[technical security requirements](docs/SECURITY.md) for the threat model.
