# Правила — компактный интерфейс

Экран использует раскрывающиеся карточки: название, адресат, статус; описание,
наказание и действия открываются внутри карточки. Вкладки разделяют правила,
заявки на согласование и авторские шаблоны. Контекст отношений переключается
парой аватаров. На телефоне создание/редактирование занимает полный экран,
на планшете/Fold редактор ограничен 540 CSS px.

Поле «Наказание» выбирает существующую запись из доступного через API списка
`discipline-records`. Сохраняются условия её текущей версии — копия в содержимом
правила, а не живая связь с записью. Изменение исходного наказания не меняет
принятые условия правила. Выбор не назначает и не запускает наказание; его
выполнение по-прежнему проходит отдельный существующий процесс согласия.
«Без наказания» явно очищает условия. Старое текстовое значение можно оставить,
даже если соответствующая запись отсутствует/недоступна.

Для предложения добавления/изменения используется тот же выбор условий.
Серверные проверки прав, точной версии и согласия остаются обязательными;
публикация шаблона не означает согласие адресата. Личная приостановка и отзыв
согласия не превращаются в запрос разрешения. API и схема БД не менялись.

Пользовательское название раздела — «Наказания». Внутреннее имя `discipline`
и URL сохранены для совместимости. Нативные изменения есть в исходниках Android,
но пока не собраны и не проверены на устройстве: текущая итерация запрещает сборки.
