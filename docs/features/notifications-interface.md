# Интерфейс уведомлений

Реализован второй показанный вариант «Две зоны»: каналы доставки слева, тихие часы справа. На телефоне зоны идут последовательно. Общие бархатный слой и параллакс сохранены, сплошной фон формы убран. Компактная навигация соответствует обновлённым страницам. Это персональные настройки: вверху личный аватар, без выбора отношений.

Два доступных канала — `in_app` и `telegram`. Переключатель Telegram управляет предпочтением доставки, а `telegram_connected` отдельно показывает фактическое подключение. Подсказка содержит существующую команду `/notifications_on`; приложение не отправляет её и не подключает бота от имени пользователя. Пояснения о доставке и отменённых сообщениях раскрываются по запросу.

Тихие часы используют время профиля, без вычисления новых часовых поясов в клиенте. Пока режим выключен, время видно, но поля недоступны. При включении нужны два корректных разных времени; переход через полночь разрешён. Сохранение использует прежний PATCH `/me/notifications` с `expected_version`. Успех показывается после ответа сервера; ошибка сохраняет черновик, конфликт версии предлагает загрузить актуальные данные. API, схема и серверная логика доставки не изменялись.

На ширине до 760 CSS px перезагрузка перенесена к аватару в верхнюю строку, поля времени остаются в две колонки, сохранение занимает ширину содержимого. На 389×844 CSS px его низ находится примерно на y=763, выше нижнего меню на y=783. На меньшей высоте страница прокручивается с нижним запасом. Переключатели имеют цель нажатия через подпись высотой 44 px, видимый focus; анимации отключаются при reduced motion, forced-colors возвращает native checkbox.

Android: `NativeNotificationScreen` вынесен в предметный файл `NativeNotificationsScreen.kt`, применены переключатели, независимый статус бота, раскрываемые подсказки и две колонки от 720 dp. Сохранены старые callbacks/DTO и test tags, добавлен доступ к перезагрузке при ошибке загрузки. Экран включён в существующую нижнюю навигацию. Instrumentation-проверка дополнена проверкой недоступности времени при выключенном режиме. Android не собирался и на устройстве не проверялся.

Проверено в локальном браузере: сохранение без изменения значений, подтверждённое сервером; включение тихих часов, ошибка одинаковых границ, допустимость 22:00–08:00, раскрытие обеих подсказок, перезагрузка. Изменённый черновик тихих часов не сохранялся; в конце возвращены исходные значения. Каналы не отключались, бот не подключался, сообщения не отправлялись. Проверены 1440×1024, 1024×1194, 854×769 и 389×844 CSS px: горизонтального overflow нет, ошибок браузера нет. Web typecheck и 22 Vitest проходят; scoped diff whitespace check проходит.

Снимки и совмещённые сравнения — `artifacts/design/ui-context/notifications-*`, отчёт — `design-qa.md`. Сборки, коммиты и деплой не выполнялись. Telegram WebView, физические сенсорные устройства и Android остаются вне выполненной проверки.
