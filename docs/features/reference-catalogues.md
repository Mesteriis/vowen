Общие поля строго соответствуют запросу: `uid UUID PRIMARY KEY`, `name TEXT NOT NULL`, `description TEXT NOT NULL DEFAULT ''`, `icon TEXT NULL DEFAULT NULL`, `thumbnail TEXT NULL DEFAULT NULL`, `url TEXT NULL DEFAULT NULL`, `extra JSONB NOT NULL DEFAULT '{}'`. Название непустое и уникально внутри таблицы без учёта регистра через lower(name). Иконка — необязательный локальный путь. Эти записи не содержат персональных выборов участников.

Активные фикстуры лежат отдельными JSON-файлами в `backend/src/vowen/modules/references/fixtures/v15/`, позы, категории и новые связи — в `fixtures/v20/`; стабильные UUID не меняются при повторной загрузке. Всего 438 записей справочников (без учёта M:N-связей). Для повторного импорта есть `appctl references seed`: добавляет недостающие записи, не перезаписывая существующие. Перед CLI/миграциями явно задавать DATABASE_URL целевой базы. Начальное заполнение выполняет Alembic 0027, сокращение зон — 0028, nullable URL и расширение практик до 100 — 0029. Исторические снимки IANA отделены от активных фикстур. 24 региональные зоны сохраняют IANA ID, включая UTC/Madrid, и не фиксируют сезонные UTC-смещения.

«Предпочтения в поле» и «предпочтения в гендере» исключены по уточнению пользователя. Существующие отношения в БД и личные профили не менялись; при сокращении справочника строки timezone в профилях не переписываются.

API: GET `/references/{kind}` доступен аутентифицированным участникам. Допустимые kind: biological-sex, genders, practices, practice-categories, poses, pose-categories, participant-compositions, devices, body-parts, materials, role-scenarios, interaction-formats, venues, health-conditions, allergens, timezones, relationship-types. POST `/administration/practices` — только действующему администратору. Поля создания: name, description, icon, extra, category_uid, device_uids, body_part_uids; uid назначается сервером. Изменение прав и добавление практики синхронизируются существующей DB-блокировкой администрации. Конкурентный повтор названия возвращает REFERENCE_EXISTS, не создавая дубль. JSON ограничен объектом до 16 KiB, внешние URL/выходы из корня в icon не принимаются. Записи не интерпретируются как код/HTML.

Web: Настройки → Справочники. Выбор из пятнадцати наборов, таблица на большом экране и список на телефоне. UID/icon/url/extra раскрываются в «Подробнее». Для практик доступна форма добавления с описанием и дополнительными атрибутами. Административное назначение вынесено в соседний таб. Данные читаются с сервера, не подменяются клиентскими константами.

Android: API/DTO и экраны справочников/добавления практики подключены в исходниках. Большие наборы отображаются порциями по 50 записей с явным «Показать ещё». Сборка и устройство не проверялись по ограничению пользователя.

Проверки: 33 PostgreSQL/API/contract-теста по справочникам, администрации, профилю, сессиям, CLI и приватности дневника; 28 web Vitest; typecheck, scoped mypy/ruff. Проверена обратимость миграции зон 24→598→24 на vowen_test без изменения практик. В браузере: пять вариантов выбора, реальные фикстуры, раскрытие атрибутов, форма с валидным/невалидным JSON и отменой, загрузка 24 зон, desktop/tablet/phone без горизонтального overflow. Тестовая практика в design-базу не добавлялась; успешный POST проверен на изолированной тестовой базе.

Локальная design-база обновлена до 0029 после закрытых резервных копий без сброса данных. Основная локальная база vowen и удалённые серверы этой задачей не менялись. Без сборок, коммитов и деплоя.

Web и Android показывают категорию и позволяют выбрать её при создании практики; Android проверен только по исходникам, без сборки.
