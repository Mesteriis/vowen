# Дневник: текст и рукопись

Главная вкладка — лента записей по датам. Новая запись создаётся только за
сегодня по часовому поясу автора; API отклоняет другую дату. Дата уже сохранённой
записи неизменяема, но её содержание можно редактировать. Поиск и фильтр по тегу
убраны из интерфейса; прежние query-параметры API сохранены для совместимости.
Настроение и теги старых записей сохраняются при редактировании.

Рукописный ввод открывает отдельный полный экран. На телефоне инструменты
расположены под листом, на планшете — сбоку. Для внутренних широких экранов Fold
web использует порог600px с отношением сторон не ниже4/5. Есть перо, ластик по
целому штриху, отмена/возврат, три толщины и возврат к клавиатуре. Письмо пальцем
включается явно; pen events принимаются без этого переключателя. Физическое
поведение S Pen и подавление ладони конкретным WebView требуют проверки на
устройстве. Поля текста используют обычную системную клавиатуру; OCR не добавлен.

API JournalContent/JournalEdit/JournalView содержит необязательное `handwriting`:
`{version:1, strokes:[{color,width,points:[{x,y,p}]}]}`. Координаты нормализованы
в пределах0..1 для страницы5:7, `p` — давление0..1, ширина относительно ширины
листа0.001..0.01, цвета — ivory/gold/rose. В текущем редакторе перо ivory.
Лимиты:500 штрихов,1500 точек на штрих,5000 точек на запись; существующий лимит
HTTP-тела также действует. Не принимаются HTML/SVG/код, произвольные поля, версии,
цвета и нечисловые/неограниченные координаты. Достаточно текста или рукописи;
пустая запись не сохраняется.

Рукопись включена в существующий зашифрованный payload записи, экспорт и проверку
версий. Миграция БД не нужна. Старые записи читаются с handwriting=null. Старый
клиент, не передающий поле при изменении текста, не удаляет уже имеющуюся рукопись;
явный null/пустой документ удаляет её, если остаётся текст. Права чтения, публикация,
явные читатели и снимок текущих участников не изменены. Доминант/оператор не
получает доступ автоматически. Черновики видит только автор.

Web сохраняет изменения по явной кнопке, предупреждает о закрытии с несохранённым
содержимым; локальная история отмены ограничена40 шагами. Это не автосохранение
после аварийного завершения. Не писать содержимое дневника в логи/localStorage.
Android использует тот же DTO/API и нормализованный ink-документ; сборка и реальный
S Pen в этой итерации не проверялись.

Обновление 2026-10-18: по решению владельца прикладные payload больше не шифруются (0035). Упоминания зашифрованного хранения выше описывают прежнюю реализацию. Права доступа/приватность API сохранены; см. ../operations/plain-payloads.md.
